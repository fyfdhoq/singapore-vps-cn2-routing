## 新加坡 CN2 VPS 的费用为什么偏高

因为 CN2 GIA 本身是计费成本很高的带宽产品。AS4809 是中国电信的 CN2 网络，GIA（Global Internet Access）是其中面向国际访问的高端层级；搬瓦工的官方文档曾提到，CN2 GIA 的 IP transit 单价可以高到接近三位数美元的量级。这条成本最终会摊到每一台新加坡 VPS 的月费上，所以你几乎看不到“$10 一个月、三网 CN2 GIA、1Gbps 带宽”这种组合。

另一件常被忽略的事：市面上不少号称“CN2”的新加坡机器，CN2 只出现在回程，去程走的是普通 163 骨干。GoMami SIN Pulse 就是这种结构——电信去程 163、回程 CN2；联通去程 10099、回程 AS9929；移动去程 CMI、回程 CMIN2。对建站和 API 服务来说，回程决定用户下载页面的速度，这个方向更重要；但如果你要做上传、推流、备份回源，去程质量同样影响体验。买之前问清楚哪一段优化，比看“CN2”三个字母更有用。

官方把 SIN Pulse 整条产品线标注为 “China Mainland Optimized Pro”，并给出中国大陆 RTT 低于 50ms 的承诺。第三方测速机构 DigVPS 对 SIN.Pulse.Mini 的实测评级为 E3（产品发布初期评级，长期稳定后通常上调），简评提到“回程为三网各自精品，去程则是三网主干直连，硬件配置相当到位”。

## 怎么自己验证回程是不是真精品

买完之后别只看 ping，要看路由。三个可核验的特征：电信回程经过 `59.43.x.x` 段（CN2 节点），联通走完 `219.158.x.x` 之后进入 9929 段，移动走 `223.120.x.x` 的 CMIN2 段。用 traceroute 或 mtr 从大陆三网分别回程一次，三条路径都能对上，线路宣传才算落实。

测试时间也要挑。第三方资料提到，普通国际线路在晚高峰 20:00–23:00 的延迟会从白天的 60–80ms 跳到 150ms 以上，丢包率从接近 0 升到 10%–30%。所以测速窗口放在 20:00–22:00 才有意义，白天的数据只是参考。

新加坡机房上线晚于香港和日本，长期晚高峰数据还在积累。参照同架构的香港 Pulse 和日本 Pulse，电信、移动方向基本能稳在标称带宽，联通偶有波动，多线程可以拉满。这个结论不能直接平移到新加坡，但至少说明同一条产品线的路由策略是一致的。

## 常见问题

**新加坡 CN2 VPS 的延迟一般是多少？** GoMami 官方给中国大陆方向承诺 RTT 低于 50ms，第三方资料提到香港节点普遍在 30ms 以内、新加坡更高一些。具体数值受你所在城市和运营商影响，看路由比看单一 ping 值可靠。

**月付能不能用 GOMAMI365 或 Hi,SIN-Y70？** 不能，这两个是年付码，要在结算页把计费周期切成 Annually 才能生效。月付方向有 Hi,SIN-M80（八折）等码，适用范围以结算页显示为准。

**流量跑完会怎样？** 限速到 20 KB/s，不停机、不额外扣费，下个计费周期恢复。按日均流量乘 30 再留 20% 余量估套餐，比较稳妥。

**能换 IP 吗？** 可以通过工单申请，IP 被墙这类正当理由通常会支持，具体以工单回复为准。IPv6 是否提供建议下单前先问清楚。

**新加坡节点适合做什么？** 面向东南亚的独立站和电商、跨境 API 中转、需要同时覆盖大陆与东南亚用户的业务。纯大陆访客为主的站，香港延迟更占优。
